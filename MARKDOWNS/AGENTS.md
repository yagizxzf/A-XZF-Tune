# A-XZF-Tune çalışma kılavuzu

Bağımsız, MIT lisanslı Roblox dört tekerlekli araç kiti. A-Chassis fork'u değildir; upstream kod, Tune tabloları veya model mekanikleri kopyalanmaz. Hedef: parçalı herhangi bir araç gövdesini açık bir rig sözleşmesiyle bağlamak, modüler fizik, güvenli ağ girdileri, kurulum denetimi ve ölçülebilir testler.

Gerçek kök bu Git deposudur. Başlangıç sırası: bu dosya, HANDOVER.md, ROADMAP.md, PROGRESSION.md son kayıtları. Dört süreklilik belgesi yalnızca MARKDOWNS/ altında tutulur. Geçmiş kayıtlar korunur; gerçek İstanbul zamanıyla yeni kayıt eklenir.

Yığın: Luau, Roblox Studio, Python 3 (bağımlılıksız paketleme), Rojo uyumlu proje. `src/Shared`: saf hesaplar/şema; `src/Server`: fizik/ağ/yaşam döngüsü; `src/Client`: sürücü girdisi; `examples/`: bağımsız araç ve pist üretimi; `tests/`: sunucu birim/entegrasyon testleri; `tools/`: paketleme; `docs/`: kullanıcı belgeleri; `evidence/`: gerçek test çıktıları.

Doğrulanmış komutlar: `python tools/build.py`; Windows'ta `python tools/check.py --compiler .tools/luau/luau-compile.exe --runtime .tools/luau/luau.exe`. Python 3.10+, Luau 0.744; kurulum/hash docs/INSTALLATION.md. 61 Luau dosyası derlenir (59 paket scripti + 2 görsel probe), 93 headless sözleşme testi çalışır, paket byte eşitliği denetlenir. Studio birim girişi `require(game.ServerStorage.AXZFTests.RunUnitTest)()`; çok istemci komutu docs/TESTING.md. Rojo yolu sunuldu ama bu makinede Aftman shim yapılandırılmadığı için doğrulanmadı. Studio hedefi: A-XZF-Tune, placeId 72435697524161. Var olan ServerStorage.R3dTuxedo içeriğini değiştirme. Workspace.Baseplate/SpawnLocation korunur. Studio çalışması yerel edit/play; canlı yayınlama, satın alma ve kalıcı veri erişimi yok.

Kurallar: tek kaynak Git'teki Luau dosyaları; Studio kopyaları bu kaynaklardan kurulur. Client yalnızca sınırlı kontrol niyeti gönderir; fizik sunucuda. NaN/Inf, sıra, koltuk yetkisi, hız sınırlama ve zaman aşımı doğrulanır. Dinamik require(assetId), loadstring ve üçüncü taraf yürütülebilir kod yok. Imported art karantinada incelenir; açık yeniden dağıtım hakkı yoksa Git'e konmaz. Model kimliği/lisansı ile kit lisansı ayrıdır. Güvenilir olmayan asset kodu Play'de çalıştırılmaz.

Production-ready iddiası yalnızca doğrulanmış release kapıları kapanınca yapılır. Tek istemci testini multiplayer veya mobil test gibi raporlama. Yapılmayan kontrolleri açıkça kaydet.

0.2 kaynakları: ui/runtime onaylı native cockpit verisi/controller; vfx/runtime MIT Emit/Build ve özgün VehicleRecipes; examples/VehicleTune araç içi Türkçe rehber. Yerel dış-art sahne .rbxl ve native paketi ignore edilir; docs/ASSETS.md opsiyonel rbxmk yolunu açıklar. Kullanıcı HUD için açıkça yuvarlak sürümü onayladı; tekrar onay gerekmez. VFX için roblox-vfx kullanıldı.

Studio güncellemelerinde açık editör buffer'ını da eşitlemek için ScriptEditorService.UpdateSourceAsync kullan. StarterPlayerScripts gibi korumalı mevcut container'lara Parent atama. GUI doğrulamasını yalnızca ayrı demoda değil, kullanıcının gerçek açık hedefinde de yap. Default Fleet.start UI kuruluysa cockpit şablonunu otomatik hazırlar.


0.3: Park=P ayrı kalıcı park isteği, Handbrake=Space arka el freni; parkı clearInput/exit otomatik bırakmaz. Yeni Controls.Park varsayılanı eski Handbrake=P remap'iyle çakışırsa açıkça başka benzersiz tuş girilmeli. Araç Tune şablonunun49 alanı açıklamalıdır; gerçek Workspace araçlarının Tune kopyalarını da güncelle, yalnızca şablonda bırakma. TuneEditor.install Edit-only; mevcut Tune için korunacak değerler açıkça verilir, bilinmeyen/legacy modül yürütmez. RollInfluence/AntiRoll/RollDamping ayarlanabilir. Mobil ikonlar tek Lucide paketi, ISC/Feather MIT bildirimi licenses/Lucide-LICENSE.txt ve NOTICE.md içinde korunur. Kullanıcı simgeli sürümü açıkça onayladı. Görsel geri bildirim ui/REVIEW.md içinde proje kapsamında tutulur.


0.4 güncel UI: kullanıcının yeni isteği önceki Lucide görünümünü değiştirir. Özgün image_gen pedal/el freni rastrları ve temalı sol/sağ düğmeleri, ayrı alt-sol/alt-sağ/el-freni/yardımcı grupları kullanılır. Fiziksel tasarım onaylandı; kullanıcı direksiyon görselini sol/sağ ile değiştirip doğrudan uygulamayı istedi, ikinci kez onay gerekmiyor. Kaynak/prompt/provenance ui/art/v4; eski Lucide dosyalarının bildirimi korunur ama aktifMobile data ikon kullanmaz. UI export 9333 headless Edge açık kalırsa yalnızca doğrulanmış --headless --remote-debugging-port=9333 cdp-* yardımcısını kapat; görünür kullanıcı tarayıcısına dokunma. Aksi halde eski DOM export edilebilir; Data ve HTML gruplarını kontrol et.

WheelVisuals LocalScript zorunlu paket parçasıdır; serverRig motorlarına AXZFWheelVisual tag/yarıçap/eksen metadata verir. ServerC0 yalnızca süspansiyon/direksiyon, istemciMotor6D.Transform görsel roll içindir; fizik/yetki client'a geçmez. WheelMotion roadRPM = |hız|/(2*pi*Radius)*60; motor devri vites/final oranıyla ayrıdır. Teker yönü local-X negatifileri, pozitifgeri; görsel dt fizik dt sınırıyla kesilmez. Test probeları tools/visual-probes, Studio Client-only; aracı hareket ettirip çalıştır. Geçmişe ait evidence/v3 dosyalarını yeni test için yeniden yazma; ui/render.mjs AXZF_UI_CHECK_RECORD env ile sürümlü çıktı alır.

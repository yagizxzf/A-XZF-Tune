# Driving UI design

Requested reference: A-Chassis-style driving information and discoverable controls. Original flat cockpit treatment: charcoal panels, warm amber highlights, large speed, gear, RPM segments, parking status. No upstream UI code/art or icon pack copied. Text labels replace decorative icons. All surfaces are native Frames/TextLabels/TextButtons; no raster texture is required for this flat style.

Review pages are generated by build.py, not hand edited. Sample values are only HTML previews. Desktop and mobile controls, hidden-help, parking and recovery states are shown. H toggles key help; mobile buttons stay available. Units are studs/second unless a project explicitly sets a conversion.

Skill requires explicit design approval before Roblox UI import. Physics, migration, Tune and VFX work can proceed while the preview is reviewed.

Final direction: original charcoal/amber circular dial, chosen after the developer asked for a round A-Chassis-like gauge. Explicit approval received before Studio import. Responsive runtime layout and touch target checks are documented in docs/HUD.md.

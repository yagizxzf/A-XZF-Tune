# Physical control artwork

Generated with the built-in image_gen tool, transparent background requested. Original outputs were copied into this project; no mobile-game artwork was copied. Layout-only references: official Google Play pages for CarX Street and Car Parking Multiplayer 2 (links in provenance.json).

## control-atlas.png

Create one production game UI sprite atlas: a square transparent PNG with an EXACT evenly divided 2 by 2 grid. Each of the FOUR cells contains ONE standalone physical automotive control object, well separated with generous transparent margins, no object crosses a cell boundary. Top-left: a tall narrow accelerator/gas pedal with brushed silver metal footplate, four long vertical black rubber grip insets, visible black mounting stem. Top-right: a clearly wider, shorter rectangular brake pedal with three broad horizontal black rubber treads and a silver mounting stem. Bottom-left: a recognizable mechanical handbrake lever, angled diagonally from lower left base toward upper right grip, black textured rubber grip, silver release button and graphite metal pivot/base. Bottom-right: a black and satin silver three-spoke sports steering wheel, front view, perfectly circular with a small plain amber circular centre hub, no logo. All four share the SAME polished realistic game prop art style, softly beveled machined metal, dark rubber, crisp silver edge highlights, a subtle warm amber accent. View all physical objects from a consistent almost frontal slight overhead angle so silhouettes are unmistakable at 80-160 pixel mobile HUD sizes; steering wheel front view. High contrast physical object renders, not flat line icons, no outline iconography. Each object large within its own cell, fully visible with 15% clear margin. Transparent alpha background everywhere around all objects, no background tile, no cards, no floor or cast shadow outside the object silhouette. No letters, no text, no numbers, no brand marks, no watermark. Original artwork for an open-source Roblox driving HUD; do not copy any existing game's art. Square 2048x2048 if possible.

Output:1254×1254 RGBA. The steering wheel is superseded and unused in the final UI.

## steering-buttons.png

One original game UI sprite sheet with TWO separate matching physical steering arrow push-buttons placed side by side, LEFT button on left half and RIGHT button on right half. Exactly two objects, equal size and design. Each is a chunky automotive dashboard push-button: satin brushed silver chamfered square metal bezel, inset dark charcoal textured rubber face, a large clearly visible raised ivory chevron pointing LEFT on left button and RIGHT on right button. Tiny warm amber reflections on lower metal rim. Realistic polished 3D automotive control object renders, same aesthetic as brushed stainless car pedals and black rubber handbrake; NOT flat icons, NOT line-art, NOT text labels. Frontal view with a very slight overhead perspective, crisp high-contrast silhouette, legible at 80 pixels. Transparent alpha background, no background cards/floor/cast shadow beyond objects. Two objects must remain entirely inside their own left/right half of the canvas with generous 15% transparent padding and a wide transparent gap. Wide landscape 1536x1024 layout if possible, a consistent neutral studio light from upper left. No words, letters, numbers, logos, badges, watermarks or other objects. Only the engraved chevron arrow shapes on the two actual physical rubber push buttons.

Output:1536×1024 RGBA. Both directions used. HTML crops/rendered through the standard UI export, preserving source images. Five runtime images uploaded; one near-identical handbrake raster hash is aliased rather than re-uploaded (provenance.json).
